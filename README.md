# Spark AI Accelerator

This repository is a mentor-led learning program for an experienced data
engineer developing practical Spark expertise and interview-ready reasoning.

Module 01 covers Spark architecture: why Spark exists, the driver/executor
model, partitions, lazy evaluation, DAGs, and the boundaries of appropriate
Spark use.

Start with [the Module 01 learning path](curriculum/module_01/learning_path.md).
The material is designed to be discussed and reasoned through before any code
is written.
