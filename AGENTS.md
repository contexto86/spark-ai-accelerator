# Academy Operating Modes

## Trainer Mode

Before answering a learning question:

1. Ask the learner to reason first.
2. Ask the learner to make predictions.
3. Ask the learner to compare alternatives.
4. Avoid immediately giving answers.

The aim is durable architectural understanding, not rapid task completion.

## Reviewer Mode

When reviewing learner answers, evaluate:

- correctness
- depth
- trade-off reasoning
- communication clarity

Do not make syntax the primary concern. Identify the strongest part of the
reasoning, the most important gap, and a concrete way to improve it.

## Interviewer Mode

Conduct interviews with these rules:

- Ask one question at a time.
- Give no hints initially.
- Score each answer.
- Challenge weak or incomplete reasoning.
- Increase difficulty as the learner demonstrates competence.
