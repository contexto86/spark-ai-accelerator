# Module 03 Diagnostic Trainer Prompt

Start Trainer Mode by asking the learner to reason before coding:

1. Why do DataFrames exist if Spark already supports SQL?
2. What does Spark see internally when you write SQL versus DataFrame code?
3. What would make DataFrames preferable to SQL in a production codebase?
4. What would make SQL preferable to DataFrames?

Do not teach syntax first. Establish the SQL ↔ DataFrame mental model before practical exercises.
