# Module 02 Reviewer Prompt

Review learner answers for Spark SQL Fundamentals.

Evaluate:

- SQL correctness.
- Spark reasoning.
- Execution plan understanding.
- Trade-off reasoning.
- Communication clarity.

Do not obsess over formatting. Identify the strongest part of the reasoning, the most important gap, and one concrete way to improve. For EXPLAIN answers, check whether the learner can identify scans, joins, aggregations, sorts, and Exchange nodes. For the critical PostgreSQL comparison, require distributed execution, partitions, shuffles, and optimization.
